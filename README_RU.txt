Oxford 3000 Pro — НОВОЕ ОТДЕЛЬНОЕ ПРИЛОЖЕНИЕ

Старый проект Oxford-3000 не требуется и не изменяется.

Что есть в новой версии:
• все 3000 слов с русским произношением и переводом;
• уроки 20 / 50 / 100 / 500 / 1000 / 3000 слов;
• умное повторение: Не знаю / Трудно / Знаю;
• дневная цель и серия дней;
• список сложных слов;
• тесты EN→RU, RU→EN, на слух и написание;
• автоматический аудиоурок EN → пауза → русский;
• регулировка скорости и паузы;
• рассказы на 100 / 300 / 500 / 1000 целевых слов;
• главы по 100 слов, подсветка слов и перевод;
• продолжение с последнего места;
• PWA-установка и офлайн-кэш.

Для публикации на GitHub Pages загрузите ВСЕ файлы из этой папки в отдельный новый репозиторий.
