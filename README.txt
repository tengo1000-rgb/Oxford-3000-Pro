Oxford 3000 Trainer v11 — проверенная версия

Что исправлено и добавлено:
- 3000 исходных строк проверены: пустых английских слов, произношений и переводов нет.
- Технические дубли и повторные значения одного headword объединены: 2979 уникальных карточек.
- Для омографов сохранены разные значения и, где нужно, разные произношения (close, live, tear, wind, used и др.).
- Слова IT/it и May/may не смешиваются: регистр учитывается там, где он меняет значение.
- Глаголы, существительные, прилагательные, наречия, местоимения, предлоги, союзы, артикли/определители, числительные и междометия разделены.
- Слова с несколькими грамматическими ролями не дублируются в основном словаре; есть отдельный фильтр «Несколько ролей».
- Исправлена генерация примеров для многозначных слов: они больше не считаются автоматически глаголами.
- Кнопка «Другой пример» теперь перебирает до 12 разных вариантов, а не только 5.
- Добавлены безопасные примеры для модальных глаголов can/could/may/might/must/should/will/would.
- Исправлена ошибка тестов, из-за которой одна неправильная попытка могла считаться как две ошибки.
- Для распространённых американских форм показывается британский вариант (color → colour и т. п.) без создания дубля.
- PWA, офлайн-кэш, аудиоурок, тесты, интервальное повторение, избранное, поиск и прогресс сохранены.

Примечание: словарь хранит основные русские значения, а не полный набор всех возможных словарных значений каждого слова.

- Для встроенных примеров русский перевод хранится в приложении. Для загружаемых словарных примеров перевод предложения может формироваться отдельно; перевод самого слова хранится локально.
